# Figma'ya Yükleme Paketi

Bu klasördeki SVG dosyası Figma'ya sürükle-bırak ile aktarılmak üzere hazırlandı.

## Dosya

- `dashboard-page.svg`: 1280x720 dashboard sayfası. Yazısızdır; sadece şekiller, kart alanları, ikonlar ve grafik placeholder'ları içerir.

## Figma'ya Aktarma

1. Figma'da yeni bir design file aç.
2. `dashboard-page.svg` dosyasını Figma canvas üzerine sürükleyip bırak.
3. Import edilen objeyi seç.
4. Gerekirse `Frame selection` ile 1280x720 frame içine al.
5. Text, chart ve Power BI placeholder'larını Figma içinde istediğin gibi ekle.

## Not

Figma REST API şu anda mevcut bir design file'a bu tip objeleri doğrudan yazmaya uygun değildir. En güvenli akış SVG import veya Figma plugin üzerinden aktarmadır.
